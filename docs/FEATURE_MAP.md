# Feature Map — MECSTEAM Website

ฟีเจอร์ที่ **มีอยู่จริงในโค้ดตอนนี้** + หลักฐานที่ Guardian ใช้เช็ก · อัปเดตไฟล์นี้ในงานเดียวกับที่แก้ฟีเจอร์เสมอ
อัปเดตล่าสุด: 5 พ.ย. 2026 (จาก Audit ใน "MECSTEAM Website (MID) — Master Plan & Handoff")

สถานะ: ✅ ผ่าน · 🟡 ใช้ได้แต่ไม่ตรงเกณฑ์ · 🔴 ต้องแก้ก่อนใช้จริง · ⚠️ รอเช็กสด

## ฟีเจอร์

| ฟีเจอร์ | เข้าถึงยังไง | หลักฐานว่าทำงาน | สถานะ |
|---|---|---|---|
| Smart Sticky Header | เลื่อนลง > 2 เท่าความสูง header | สไลด์ขึ้นภายใน ≤ 320ms · ไม่ซ่อนตอนเมนูมือถือเปิด | 🟡 ช้าเกิน (2000ms) |
| Scrollspy Overlay | เลื่อนพ้น Hero บนจอ > 1024px | ไฮไลต์ตรง section ทุกตัว ไม่ข้าม · ไม่ทับการ์ดที่ 1366/1920/2560px | 🔴 ทับเนื้อหา |
| Conditional CTA (FAB) | เลื่อนพ้น Hero | label ตรงกับปลายทางทุก section · ซ่อนเมื่อถึง #contact | 🟡 label Overview ผิด |
| Card reveal | hover / focus / จอสัมผัส | รายละเอียดโผล่ · มือถือเห็นถาวร | ✅ |
| Mobile nav | ปุ่ม burger ≤ 768px | เปิด/ปิดได้ · Esc · scrim · ล็อก scroll | 🟡 ยังไม่ครบ |
| Contact | #contact | ที่อยู่ = แผนที่ · อีเมลโดเมนบริษัท · tel กดโทรได้ | 🔴 อีเมลยังเป็น Gmail |
| Custom domain + HTTPS | `https://mecsteam.com` | กุญแจ 🔒 · `www` เข้าได้ | ⚠️ รอเช็กสด |
