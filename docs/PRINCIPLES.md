# Principles — กฎที่ AI ทุกตัวในทีมของนัวร์ใช้ร่วมกัน

ใช้กับ HQ, WebDev, Guardian, Coach, Scribe · ที่มา: แนวคิด pstack ของ Lauren Tan (poteto) + สิ่งที่นัวร์ชอบ/ไม่ชอบ

## 7 หลักการทำงาน

| # | หลัก | ทำยังไง |
|---|---|---|
| 1 | **Router + Playbook** | เลือก playbook ที่ตรงงาน แล้วคัดลอกทุกขั้นลง task list · ข้ามขั้นไหนต้องเขียนเหตุผล |
| 2 | **Done means…** | ทุกงานจบด้วยเงื่อนไขที่เช็กได้ (เทสผ่าน, CI เขียว, เห็นบนจอ) ไม่ใช่ "น่าจะใช้ได้" |
| 3 | **Evidence ไม่ใช่คำพูด** | รายงานพร้อมหลักฐาน: ผล CI, ผลเทส, screenshot, ลิงก์ source · "build ผ่าน" ไม่พอ |
| 4 | **เล่าปัญหาก่อนลงมือ** | สรุปปัญหาด้วยคำของตัวเองก่อนแตะโค้ด ให้นัวร์จับความเข้าใจผิดได้เร็ว |
| 5 | **Feature Map ต้องตรงกับโค้ด** | แก้ฟีเจอร์ → อัปเดต `FEATURE_MAP.md` ในงานเดียวกัน (บทเรียนจากเว็บ MECSTEAM: เอกสารเพี้ยนจากโค้ด 7 จุด) |
| 6 | **พลาดซ้ำ → แก้ที่ skill** | ทุกวันอาทิตย์ `/reflect` — ปัญหาที่เกิดซ้ำต้องกลายเป็นกฎ/เทส/skill ไม่ใช่จำเอา |
| 7 | **ความเข้มข้นตามความเสี่ยง** | งานเล็ก (แก้ข้อความ, สี) ทำเลย · งานที่ผิดแล้วแพง (DB migration, ลบข้อมูล, deploy) ใช้ playbook เต็ม + Guardian ตรวจ |

## นัวร์ชอบ / ไม่ชอบ

| ✅ ชอบ | ❌ ไม่ชอบ |
|---|---|
| แอปอิสระ: เตือน + ให้ตัวเลือก | บล็อก ห้ามทำ |
| ข้อมูลผิด/ชน ขึ้นสีแดงชัด ๆ | popup ยาว — อยากได้แจ้งสั้นด้านล่าง |
| ตัวเลือก "ไม่ต้องถามอีก" | highlight ค้างหลังออกจากหน้า (ไม่ clean) |
| ลากเมาส์ลื่น สมูท | overlay / คำอธิบายบังเนื้อหา |
| หน้าตามินิมอล ใช้ได้ตอนหน้าต่างเล็ก (ล็อกขนาดต่ำสุด) | Advanced ที่ "อ่อน" — ต้องเข้มและสมจริง |
| คำตอบสั้น ตาราง + ตัวหนา ไทยปนอังกฤษ | เอกสารอังกฤษล้วน · คำตอบยาวเกินเนื้อหา |
| เจอบั๊ก → โหมดทางการ: อาการ → สาเหตุ → วิธีแก้ ทีละบรรทัด | — |

## ค่าที่ยอมรับได้ (ใช้ตัวเลข ไม่ใช่คำว่า "ลื่น")

| เรื่อง | ช่วง |
|---|---|
| Animation | 150–320 ms · ใช้ `transform` / `opacity` |
| ข้อความ body บนมือถือ | ≥ 16 px |
| พื้นที่แตะ | ≥ 44 × 44 px |
| Contrast ตัวหนังสือ/ปุ่ม | ≥ 4.5 : 1 |

## สิ่งที่ห้ามทำโดยไม่ถามนัวร์

- แก้ Business facts (ชื่อบริษัท, ที่อยู่, เบอร์, อีเมล, สถิติ) — ต้องมาจากเจ้าของบริษัทเท่านั้น
- แก้ไฟล์ `CNAME` หรือค่า DNS
- เพิ่ม framework / build tool / ไลบรารีภายนอก (เว็บนี้ HTML/CSS/JS ล้วน)
